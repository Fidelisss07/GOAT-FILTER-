# Goat Filter

Kit visual para implementar o utilitário Windows de Digital Vibrance com Claude Code.

1. Extraia o ZIP na raiz do projeto ou em uma pasta que Claude Code consiga acessar.
2. Abra Claude Code no repositório e envie o conteúdo de `prompts/00-projeto.md`.
3. Os prompts numerados também podem ser enviados individualmente para ajustar cada tela.

- `logos/` — três logos completas e três símbolos isolados. SVGs em curvas, fundo transparente.
- `telas/` — PNGs de Visão geral em roxo, rosa e amarelo, além de Perfis e Configurações em roxo.
- `assets/` — recorte de cenário para a prévia. As imagens de tela são referências de layout.
- `prompts/` — especificação global e instruções por tela.

A versão roxa é a referência principal para proporções. As páginas Perfis e Configurações herdam os três temas da aplicação.
