# Goat Filter — atualização visual

Abra `telas/` para consultar os mockups e use `PROMPT-CLAUDE-CODE.md` no repositório do aplicativo. O kit inclui seis SVGs de marca com fundo transparente, o cabrito lateral separado, uma cena ilustrativa para o comparador e tokens para os três temas.

A Visão geral é a referência visual principal. Os PNGs das outras telas são mockups em rosa. A mudança de tema é feita no aplicativo pelos tokens. Os arquivos são referências e assets de interface, e o prompt orienta como adaptar o código existente.
